# ShellHacks 2024 - Static Site

This repository hosts the static GitHub Pages site for ShellHacks 2024.

## About

This is the archived static version of the ShellHacks 2024 website, hosted on GitHub Pages at [2024.shellhacks.net](https://2024.shellhacks.net).

## Structure

- `index.html` - Main landing page
- `404.html` - Custom 404 page
- `assets/` - Images and graphics
- `fonts/` - Custom fonts
- `images/` - Additional image assets
- `_next/` - Next.js static build assets
- `CNAME` - Custom domain configuration

## Deployment

This site is automatically deployed via GitHub Pages from the `github-pages` branch.

Any commits to this branch will automatically update the live site.
